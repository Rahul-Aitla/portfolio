# TDC — AI-Powered Matchmaking Operations Hub

**TDC Matchmaker Portal** is a high-performance, CRM-style internal tool designed for matrimonial operations teams. It streamlines customer management and matchmaking by combining deterministic compatibility logic with advanced AI reasoning.

---

## What Users Can Do

- Manage customer profiles and preferences in a CRM dashboard
- View AI-powered match suggestions with compatibility scores
- Track matchmaking workflows and customer interactions

---

## Key Features

- **CRM Dashboard** — Centralized view of all customer profiles and interactions
- **AI Matchmaking** — Intelligent partner suggestions using AI reasoning
- **Compatibility Scoring** — Deterministic algorithm for preference-based matching
- **Workflow Management** — Track matchmaking progress and follow-ups

---

## Tech Stack

- **Next.js** — Full-stack React framework with App Router
- **TypeScript** — Type-safe development across the stack
- **Google Gemini** — AI-powered match recommendations

---

## Architecture

1. Operations team manages customer profiles through the CRM interface
2. Compatibility algorithms score potential matches based on preferences
3. AI reasoning layer provides intelligent match recommendations
4. Workflow tracking ensures each matchmaking case progresses efficiently
