# Sundown-Studio — Professional Landing Page

**Sundown-Studio** is a visually rich brand landing page that showcases modern front-end animation techniques. It features smooth parallax scrolling via Locomotive JS, full-screen slider transitions with Swiper.js, and staggered GSAP timeline animations.

---

## What Users Can Do

- Scroll through a parallax-driven brand narrative
- View full-screen project sliders with smooth transitions
- Experience staggered reveal animations on scroll

---

## Key Features

- **Parallax Scrolling** — Locomotive JS for smooth, performant scroll effects
- **Full-Screen Sliders** — Swiper.js with responsive, touch-friendly carousels
- **GSAP Timelines** — Staggered reveal animations sequenced across sections
- **Responsive Design** — Fully responsive layout across desktop and mobile

---

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom styling with modern layout techniques
- **JavaScript** — DOM manipulation and interaction logic
- **GSAP** — GreenSock Animation Platform for timeline animations
- **Swiper.js** — Touch-enabled slider library
- **Locomotive JS** — Smooth parallax scrolling

---

## Architecture

1. User lands on the page and experiences a GSAP entrance animation
2. Scrolling triggers Locomotive JS smooth scroll with parallax effects
3. Swiper.js sliders present project showcases with full-screen transitions
4. GSAP scroll triggers activate staggered reveals for each section

---

## Development Experience

### Animation Engineering
- Built nested GSAP timelines for sequenced reveal animations
- Integrated Locomotive JS scroll speed and parallax offset controls

### Slider Implementation
- Configured Swiper.js for full-screen, touch-enabled carousels
- Custom pagination and navigation matching the brand design

### Responsive Development
- Used CSS media queries for adaptive layouts across breakpoints
- Ensured touch interactions work seamlessly on mobile devices
