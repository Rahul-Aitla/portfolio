# Sidcup Golf — Golf Club Website

**Sidcup Golf** is a professional golf club website built with **HTML, CSS, JavaScript**, and powered by **GSAP** with **ScrollTrigger** for cinematic scroll-driven animations. The design showcases the club's premium experience through immersive visual storytelling.

---

## What Users Can Do

- Browse the golf club's services and facilities
- Experience scroll-driven narrative animations
- View courses and amenities through interactive sliders

---

## Key Features

- **ScrollTrigger Animations** — GSAP-powered scroll-driven reveals and parallax
- **Interactive Sliders** — Swiper.js for showcasing courses and amenities
- **Cinematic Effects** — Staggered text reveals, parallax images, and smooth transitions
- **Responsive Design** — Fully optimized for desktop, tablet, and mobile

---

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom styling with animation support
- **JavaScript** — Interaction logic and DOM manipulation
- **GSAP** — GreenSock Animation Platform with ScrollTrigger plugin

---

## Architecture

1. User scrolls through the page triggering GSAP ScrollTrigger timelines
2. Each section reveals content with staggered animations and parallax effects
3. Swiper.js sliders present course and amenity galleries
4. Smooth scroll and responsive design ensure a polished experience

---

## Development Experience

### ScrollTrigger Engineering
- Built coordinated ScrollTrigger timelines across multiple page sections
- Implemented parallax scrolling effects tied to scroll position

### Animation Design
- Created staggered text reveals and image fade-ins
- Synced Swiper.js slider transitions with GSAP animations

### Responsive Implementation
- Ensured all animations work smoothly on mobile devices
- Used CSS media queries and flexible layouts for all screen sizes
