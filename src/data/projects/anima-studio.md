# Animastudio — AI-Powered Text-to-Animation Engine

**Animastudio** is a system that converts structured text into mathematical and educational animations using **Manim**. It uses **NLP-based parsing** to transform input prompts into animation sequences and automates the rendering pipeline with Docker.

---

## What Users Can Do

- Input structured text or prompts describing mathematical concepts
- Automatically generate educational animations
- Render animations in isolated Docker containers
- Export high-quality video explanations

---

## Key Features

- **NLP-Based Parsing** — Transforms natural language prompts into animation sequences
- **Manim Integration** — Leverages the Manim animation engine for high-quality math animations
- **Docker Automation** — Isolated rendering pipeline for scalable animation generation
- **Extensible Architecture** — Add new animation types and rendering configurations

---

## Tech Stack

- **Python** — Core programming language
- **Manim** — Mathematical animation engine
- **Docker** — Containerized rendering pipeline
- **NLP** — Natural language processing for prompt parsing
